# 安全说明（Security Notes）

本文档记录 OrionTV 中有意的、与局域网自托管场景相关的安全取舍，以及对应的缓解措施。改动相关代码前请先读这里，避免把有意的取舍当成 bug“修掉”，或把缓解措施当成多余代码删掉。

## 1. 登录凭据与明文 HTTP（M2）

- 用户填写 IP 地址或带端口的 host 作为服务器地址时，应用默认补 `http://`（见 `stores/settingsStore.ts` 的 `saveSettings`）；登录的用户名/密码以明文 JSON 发送，同一局域网内的攻击者可嗅探。
- 缓解：登录时若目标地址是非 localhost 的 `http://`，会弹出一次明确的风险提示，需用户确认后才继续登录（同一会话内只提示一次，见 `components/LoginModal.tsx`）。localhost（`localhost` / `127.0.0.1` / `[::1]`）不提示。
- 明文策略的实际来源是自定义 `xml/AndroidManifest.xml` 中的 `usesCleartextTraffic="true"`（`app.json` 里的 `networkSecurityConfig` 字段不是 Expo 支持的配置项，已被忽略，不要以它为准）。

**建议：局域网内部署 HTTPS/反代。** 局域网自托管场景下推荐的几种做法（按易用程度排序）：

1. **反向代理 + 可信证书**：在局域网内用 Caddy / nginx 给 MoonTV 服务做反代并配 HTTPS；若有自己的域名，可用 Cloudflare Tunnel 把服务暴露为 `https://` 地址（无需在电视上装证书）。
2. **自签证书**：内网 CA 签发证书并在电视系统里安装为受信任 CA；注意电视系统安装 CA 的入口因厂商而异，且部分电视不允许用户安装 CA。
3. **实在只能用 HTTP**：确保服务器只在可信的家庭局域网内可达，不要把 MoonTV 端口做公网端口转发；登录密码不要与其它服务复用。

## 2. 远程输入（手机扫码输文本）仅在可信局域网开启（L3）

- 远程输入服务是纯 HTTP，监听 `0.0.0.0:12346`（见 `services/tcpHttpServer.ts`）；4 位配对码以明文请求头传输，局域网内可被嗅探，**无法防止同一局域网内的窃听者拿到配对码**。这是一个已知取舍：配对码每次启动服务时重新生成（密码学随机数），有效期只有一次服务运行周期。
- 已有的缓解措施：
  - 配对失败锁定按**客户端 IP 分离计数**（同一 IP 连续失败 5 次后锁定该 IP 60 秒），攻击者无法通过故意输错来锁住合法用户；
  - 配对码比较使用恒定时间比较（手写按位比较，固定遍历全长），防计时侧信道；
  - TCP 服务有单连接 30 秒空闲超时、10 个并发连接上限、1MB 请求体积上限；不支持 chunked 编码的请求直接回 501。
- 使用建议：只在可信的家庭局域网内开启远程输入，用完即关；不要把 12346 端口暴露到公网或做端口转发；不要在公共 WiFi 下使用。

## 3. 生产环境日志（L17）

- 生产包没有接任何崩溃上报服务（无 Sentry DSN，不引新依赖）。`utils/Logger.ts` 的 `warn` / `error` 在生产环境会写入本地轮转日志文件，`debug` / `info` 在生产环境仍不输出；开发环境的 console 行为不变。
- **日志文件位置**：应用缓存目录下的 `oriontv.log`（`expo-file-system` 的 `Paths.cache`），Android 上为 `/data/data/com.oriontv/cache/oriontv.log`。
- **轮转策略**：上限 200KB（另有 500 行内存上限），超了丢掉最旧的行、保留最新部分；应用重启时会读回上次残留的日志续写，不会因一次启动就丢掉之前的记录；缓存目录可能被系统清理，日志不是永久保存。
- **日志内容**：warn/error 级别消息与错误堆栈（堆栈对定位生产问题很关键）。日志里不应出现凭据——调用方不要把密码、token、配对码记进日志。
- **取回方式**：
  - debug 包：接 adb 后执行 `adb shell run-as com.oriontv cat cache/oriontv.log`；
  - release 包不可 `run-as`（非 debuggable），目前没有应用内导出入口，取回需后续加一个“导出日志”（如分享文件）功能（TODO）。
- 分享日志给他人排查问题前，先检查内容是否含敏感信息（如内网地址、请求 URL 参数）。
